🤖 視覺機器學習模型

1. 本章重點摘要

本章先說明電腦視覺的挑戰（角度、亮度、規模、遮擋雜亂等），以及影像在電腦中如何以 RGB 或灰階像素矩陣表示。接著介紹三個傳統機器學習方法：SVM（分類）、KNN（距離分類）、PCA（降維），各自在電腦視覺的用途與缺點。後半進入深度學習：神經網路的結構、激活函數、輸出層（Sigmoid／Softmax）、損失函數、前向與反向傳播、梯度下降與優化器（SGD、Adam），最後是標籤編碼與評估指標。這章是下一章「卷積神經網路（CNN）」的基礎，CNN 的訓練流程完全沿用本章的神經網路觀念。

2. 章節大綱

2.1 電腦視覺的挑戰

  • 豐富的資訊量（物件類別、深度…）
  • 相機和感測器性能
  • 角度、亮度、規模（大小）、動作
  • 雜亂（Clutter）：背景複雜、物體互相遮擋
  • 型態：同一類物體有很多種外觀
  • 視錯覺（Optical Illusions）

2.2 電腦眼中的影像

  • 彩色圖片由 R、G、B 三個頻道（channel）組成，每個頻道由許多像素（pixel）組成，每個像素值介於 0～255
  • 灰階圖片只有一個頻道
  • 影像格式可表示為「高 × 寬 × 頻道數」的數字矩陣 補充

逐步展開：一張 224×224 的彩色圖有幾個數值

  1. 像素數：\(224\times224=50{,}176\) 個像素。
  2. 每個像素幾個數值：RGB 三個頻道，每個 0～255 → 3 個數值（灰階只有 1 個）。
  3. 總數：\(50{,}176\times3=150{,}528\)。對 KNN 來說，每算一次距離都要比較 150,528 個維度。

  • 什麼是機器學習：三層同心圓，人工智慧（Artificial Intelligence, AI）⊃ 機器學習（Machine Learning, ML）⊃ 深度學習（Deep Learning, DL）
    • AI：能感知、推理、行動並適應環境的程式

2.4 支持向量機（Support Vector Machine, SVM）

  • 監督式學習演算法，主要用於分類
  • 目標：找到一個「最佳超平面（hyperplane）」區分不同類別
  • 同時最大化間隔（Margin）：讓兩類資料點離超平面越遠越好，加入新資料時才能維持高準確率
  • 可做二元分類與多類別分類
  • 資料無法用一條線切開時 → 使用核技巧（Kernel Trick）把資料投影到更高維的空間再切分
  • 在 CV 的應用：圖像分類、物件偵測（判斷每個網格或偵測框是否為該物體）、語義分割（把相似區域切分）
  • 缺點：
    • 不適合大資料集：計算最佳超平面非常耗時
    • 對非線性資料處理有限：雖有 Kernel Trick，但選擇合適的 kernel function 與調參很困難
    • 多分類較複雜：原本為二分類設計，多分類需「一對一」或「一對多」轉換，增加計算成本

自己轉動超平面，找最大間隔

拖動滑桿轉動分隔線。虛線之間的寬度就是 margin；貼在虛線上的點（加粗外框）就是支持向量。按「找最佳超平面」看 SVM 會選哪一條。

Kernel Trick：切不開就「抬」到高一維

一維資料中，紅點在中間、藍點在兩側，用一個門檻值（一個點）怎麼切都切不開。加上第二個特徵 \(x^2\) 後，資料變成二維，一條水平線就能分開。補充講義用二維投影到三維的圖，這裡用一維到二維的簡化版，概念相同。

2.5 K 最近鄰（K-Nearest Neighbors, KNN）

  • 監督式學習演算法，主要用於分類，核心是以距離判斷類別
  • 基本三步驟：① 計算新樣本與所有訓練樣本的距離 ② 取最近的 K 個鄰居 ③ 多數決決定類別 補充講義以圖說明
  • 投票結果各半怎麼辦？→ K 通常設為奇數
  • 距離計算：歐幾里得距離（Euclidean Distance）、曼哈頓距離（Manhattan Distance），以及把兩者統整起來的明氏距離（Minkowski Distance）；高維時曼哈頓距離較穩健（見下方公式）
  • 在 CV 的應用：圖像分類、物件偵測、圖像分割
  • 缺點：
    • 計算效率低：預測時要計算新樣本與所有樣本的距離，資料越大越慢
    • 高維度資料表現不佳：高維空間中「距離」的概念變得不再有效
    • 無法處理非線性關係：圖像之間的關聯往往是非線性的

KNN 三步驟：點一下放新樣本

在圖上點一下放入新樣本（★）。圓圈內是最近的 K 個鄰居，由它們投票決定類別。試試把 K 設成偶數，找找看會平手的位置。

公式：距離（KNN）

$$d_{\text{Euclidean}}(\mathbf{x},\mathbf{y})=\sqrt{\sum_{i=1}^{n}(x_i-y_i)^2},\qquad d_{\text{Manhattan}}(\mathbf{x},\mathbf{y})=\sum_{i=1}^{n}\lvert x_i-y_i\rvert$$

\(n\)：維度數；\(x_i, y_i\)：兩點在第 \(i\) 維的值。

講義把兩者統整成明氏距離（Minkowski Distance）：

$$d_{\text{Minkowski}}(\mathbf{x},\mathbf{y})=\Big(\sum_{i=1}^{n}\lvert x_i-y_i\rvert^{p}\Big)^{1/p}$$
  • \(p=1\) → 曼哈頓距離（L1 norm）；\(p=2\) → 歐幾里得距離（L2 norm）
  • C3 的 L1／L2 正則化用的就是同樣的 L1、L2 norm，只是對象從「兩點的差」換成「模型參數」 補充
  • \(p\) 越大，結果越被差距最大的那一維主導；\(p\to\infty\) 時只剩最大的那一維，稱為切比雪夫距離（Chebyshev Distance）補充
\(p\)A→B（10, 1）A→C（7, 7）誰比較遠
1（曼哈頓）\(10+1=11\)\(7+7=14\)C 明顯較遠
2（歐幾里得）\(\sqrt{101}\approx10.05\)\(\sqrt{98}\approx9.90\)幾乎一樣，B 略遠
∞（切比雪夫）補充\(\max(10,1)=10\)\(\max(7,7)=7\)B 明顯較遠

同樣三個點，換一個 \(p\) 結論就反過來：\(p\) 小時每一維都算得一樣重，\(p\) 大時只看差距最大的那一維。

逐步展開：講義例子 A(0,0)、B(10,1)、C(7,7)，B 和 C 誰離 A 比較遠？

  1. 先算每一維的差：A→B：x 差 \(10-0=10\)、y 差 \(1-0=1\)；A→C：x 差 7、y 差 7。
  2. 歐幾里得（直線距離）A→B：每一維的差先平方再加總，最後開根號：\(\sqrt{10^2+1^2}=\sqrt{100+1}=\sqrt{101}\approx10.05\) 就是國中的畢氏定理：兩股是 10 和 1，求斜邊。
  3. 歐幾里得 A→C：\(\sqrt{7^2+7^2}=\sqrt{49+49}=\sqrt{98}\approx9.90\)
  4. 歐幾里得的結論：10.05 vs 9.90，B 和 C 幾乎一樣遠。 平方會把大的差距放得更大：B 的 \(10^2=100\) 一項就佔了 101 中的 100，y 方向的差異幾乎被忽略。
  5. 曼哈頓（走棋盤格）A→B：每一維的差取絕對值後直接加：\(|10|+|1|=11\)
  6. 曼哈頓 A→C：\(|7|+|7|=14\)
  7. 曼哈頓的結論：11 vs 14，C 明顯比較遠。曼哈頓不平方，每一維的差異都算得一樣重，所以「兩維都有中等差異」的 C 被判得比較遠。

逐步展開：明氏距離怎麼算（A(0,0)、B(10,1)、C(7,7)）

  1. 公式拆成三個動作：① 每一維的差取絕對值 ② 各自做 \(p\) 次方再加總 ③ 最後開 \(p\) 次方根。 先放大（\(p\) 次方）再縮回（開 \(p\) 次方根），單位才會和原本的距離一致。
  2. 每一維的差：A→B 是 \((|10-0|, |1-0|)=(10, 1)\)；A→C 是 \((7, 7)\)。這一步和 \(p\) 無關，後面只換 \(p\)。
  3. \(p=1\)：一次方加總：A→B \(=10^1+1^1=11\)；A→C \(=7+7=14\)。開 1 次方根等於不變 → 11 vs 14，就是曼哈頓距離。
  4. \(p=2\)：平方加總：A→B \(=10^2+1^2=100+1=101\)；A→C \(=7^2+7^2=49+49=98\)。開平方根 → \(\sqrt{101}\approx10.05\)、\(\sqrt{98}\approx9.90\)，就是歐幾里得距離。
  5. \(p=3\)：三次方加總：A→B \(=10^3+1^3=1000+1=1001\)；A→C \(=7^3+7^3=343+343=686\)。開立方根 → \(\sqrt[3]{1001}\approx10.003\)、\(\sqrt[3]{686}\approx8.82\)，B 已經明顯比較遠。 1001 裡有 1000 來自 x 方向，y 方向的 1 只佔千分之一，A→B 幾乎就等於 10。
  6. \(p\to\infty\)：次方越大，最大的那一項越壓倒其他項，結果趨近「最大的那一維」：A→B → \(\max(10,1)=10\)；A→C → \(\max(7,7)=7\)。這就是切比雪夫距離 補充。
  7. 看出規律：A→C 兩維一樣大，可以化簡成 \((2\times7^p)^{1/p}=7\times2^{1/p}\)：\(p=1\) 時 14、\(p=2\) 時 9.90、\(p=3\) 時 8.82……一路往 7 降；A→B 則幾乎一直停在 10。兩者在 \(p\approx1.91\) 時一樣遠（都約 10.06），\(p\) 比這小 C 比較遠，比這大 B 比較遠 補充。 所以「誰比較遠」不是絕對的，取決於你用哪一種距離；這也是講義問「什麼情況下曼哈頓距離比較穩健」的原因：\(p\) 越小，越不會被單一維度的大差距主導。

歐幾里得 vs 曼哈頓：誰比較遠？

講義例子：A(0,0)、B(10,1)、C(7,7)。拖動 B 或 C（或直接改座標），看兩種距離的結論是否一致。

講義的結論：歐幾里得距離下 B、C 幾乎一樣遠（B 在 x 軸的巨大差異主導了計算）；曼哈頓距離下 C 明顯比較遠，反映「兩個維度都有中等差異」。想像在 1000 維的空間裡，歐幾里得距離會完全由少數差異最大的維度決定，曼哈頓距離則能更穩健地反映所有維度的整體差異。

2.6 主成分分析（Principal Component Analysis, PCA）

  • 降維技術：在保留主要資訊的同時減少特徵數量
  • 核心：把高維資料投影到低維空間，新的軸（主成分）是資料變異性最大的方向
  • 在 CV 的應用：
    • 圖像降維：某些任務不需要色彩（如邊緣偵測），直接用灰階圖可減少計算量、加快訓練
    • 圖像去噪：夜間視野不佳或畫質差的畫面，可透過降噪得到較清晰的圖像
  • 缺點：
    • 對非線性資料處理有限：PCA 是線性降維，假設變異沿直線方向分佈
    • 訊息遺失：只保留變異最大的方向，可能損失重要細節，在需要細節判斷的任務表現不佳

PCA：把二維資料降成一維

轉動投影軸，所有點會垂直投影到這條線上（變成一維）。投影後的「變異量」越大，保留的資訊越多；按「找主成分」看 PCA 選的方向。

2.7 深度學習 × 電腦視覺：神經網路基礎

  • 簡單神經網路：輸入層 → 隱藏層 → 輸出層
  • 每個節點（node）：輸入乘上權重、加上偏差（bias），再經過激活函數
  • 激活函數（Activation Function）：引入非線性（non-linearity）
  • 輸出層（分類任務）：二元分類 → Sigmoid；多類別分類 → Softmax
  • 前向傳播（Forward Propagation）：資料從輸入一層層算到輸出，得到預測

公式：Sigmoid 與 Softmax

講義以圖呈現，以下為標準寫法 補充

$$\sigma(z)=\frac{1}{1+e^{-z}},\qquad \text{softmax}(z_i)=\frac{e^{z_i}}{\sum_{j=1}^{K}e^{z_j}}$$

\(z\)：輸出層節點的原始分數（logit）；\(K\)：類別數。

逐步展開：Sigmoid 與 Softmax 怎麼把分數變成機率

  1. 先認識 \(e^{z}\)：\(e\approx2.718\)。\(e^{z}\) 永遠是正數，\(z\) 越大它越大：\(e^0=1\)、\(e^1\approx2.718\)、\(e^2\approx7.389\)、\(e^{-2}\approx0.135\)。 機率不能是負的，所以先用 \(e^z\) 把任何分數（可正可負）變成正數。
  2. Sigmoid，\(z=0\)：\(\sigma(0)=\dfrac{1}{1+e^{0}}=\dfrac{1}{1+1}=0.5\)，一半一半。
  3. Sigmoid，\(z=2\)：\(\sigma(2)=\dfrac{1}{1+e^{-2}}=\dfrac{1}{1+0.135}\approx0.881\)。\(z\) 越大越接近 1，越小越接近 0。
  4. Softmax，\(z=(2,1,0)\)，第一步取 \(e^z\)：\((e^2,e^1,e^0)=(7.389,\ 2.718,\ 1)\)
  5. 第二步加總：\(7.389+2.718+1=11.107\)
  6. 第三步各自除以總和：\(7.389\div11.107\approx0.665\)、\(2.718\div11.107\approx0.245\)、\(1\div11.107\approx0.090\)。 除以總和之後三個數加起來剛好是 1，就變成機率分布了。
  7. 觀察：分數差 1（2 和 1），機率差了快 3 倍（0.665 vs 0.245），因為 \(e^1\approx2.7\)。Softmax 會放大分數之間的差距。

Sigmoid：二元分類的輸出

拖動 \(z\)，看 \(\sigma(z)\) 在曲線上的位置。\(\sigma(0)=0.5\)；\(z\) 很大或很小時曲線變平，斜率（梯度）接近 0，這就是 C2 會提到的「梯度消失」。

2.8 訓練損失（Training Loss）

  • 衡量預測與真實值的差距，並據以調整權重
  • 分類任務：交叉熵（Cross-Entropy），比較「真實機率分布」與「預測機率分布」
  • 迴歸任務：均方誤差（Mean Squared Error, MSE）或平均絕對誤差（Mean Absolute Error, MAE）

公式：損失函數

講義以圖呈現，以下為標準寫法 補充

$$L_{CE}=-\sum_{i=1}^{K}y_i\log\hat{y}_i,\qquad \text{MSE}=\frac{1}{N}\sum_{j=1}^{N}(y_j-\hat{y}_j)^2,\qquad \text{MAE}=\frac{1}{N}\sum_{j=1}^{N}\lvert y_j-\hat{y}_j\rvert$$

\(y_i\)：真實機率分布（one-hot）；\(\hat{y}_i\)：預測機率分布；\(N\)：樣本數。

Softmax ＋ 交叉熵

調整三個類別的分數 \(z\)，看 Softmax 機率與交叉熵損失。預設 \(z=(2,1,0)\)、正確答案是第 1 類 → 機率約 (0.665, 0.245, 0.090)，損失約 0.408。把正確答案改成第 3 類，損失會跳到約 2.41。

迴歸損失的例子：真實值 (3, 5)、預測 (2, 7) → MAE = (1+2)/2 = 1.5；MSE = (1+4)/2 = 2.5。

逐步展開：交叉熵、MSE、MAE

  1. 交叉熵的 one-hot：正確答案是第 1 類 → \(y=(1,0,0)\)。代入 \(-\sum y_i\log\hat{y}_i\)，乘到 0 的項都消失，只剩 \(-1\times\log\hat{y}_1\)。 所以交叉熵其實只看一件事：模型給「正確答案」多少機率。
  2. 代入 Softmax 的結果：\(\hat{y}=(0.665,0.245,0.090)\)，\(L=-\log0.665\approx0.408\)（log 是自然對數 ln）。
  3. 如果正確答案是第 3 類：\(L=-\log0.090\approx2.41\)。模型給正確答案的機率越低，損失越大。 \(-\log\) 的特性：機率 1 → 損失 0；機率趨近 0 → 損失趨近無限大。
  4. 迴歸：先算誤差：真實 (3, 5)、預測 (2, 7)，誤差 \(3-2=1\)、\(5-7=-2\)。
  5. MAE（平均絕對誤差）：取絕對值再平均：\((|1|+|-2|)\div2=3\div2=1.5\)
  6. MSE（均方誤差）：平方再平均：\((1^2+(-2)^2)\div2=(1+4)\div2=2.5\) 平方讓大的誤差（−2）被罰得更重：它在 MAE 佔 2/3，在 MSE 佔 4/5。

2.9 反向傳播與梯度下降

  • 反向傳播（Backward Propagation）：從輸出端往回計算損失對每個權重的梯度（Gradient）
  • 梯度下降（Gradient Descent）：優化演算法，依損失的梯度更新權重，使損失最小化
  • 學習率（Learning Rate）：決定每次更新的步伐大小
    • 太大 → 更新過快，可能跳過最佳解
    • 太小 → 更新太慢，可能到不了最佳解
    • 是需要調整的超參數（Hyperparameter）

公式：梯度下降

$$w \leftarrow w-\eta\,\frac{\partial L}{\partial w}$$

\(w\)：權重；\(\eta\)：學習率；\(\partial L/\partial w\)：損失對權重的梯度。例：\(w=2\)、梯度 \(=4\)、\(\eta=0.1\) → \(w=2-0.1\times4=1.6\)；若 \(\eta=1\) → \(w=-2\)（步伐太大，可能跳過最佳解）。

逐步展開：用 \(L(w)=w^2\) 走梯度下降（最低點在 \(w=0\)）補充

  1. 梯度是什麼：\(\partial L/\partial w\) 就是損失曲線在 \(w\) 這點的斜率。\(L=w^2\) 的斜率是 \(2w\)；在 \(w=2\)，斜率 \(=4\)（正的 → 往右是上坡）。 這剛好就是上面例子的「梯度 = 4」。
  2. 為什麼是減號：斜率為正代表往右會變高，所以要往左走 → \(w\) 減去梯度。斜率為負時減負數等於往右走，一樣是下坡方向。
  3. 第 1 步（η = 0.1）：\(w=2-0.1\times4=2-0.4=1.6\)
  4. 第 2 步：新的斜率 \(2\times1.6=3.2\)；\(w=1.6-0.1\times3.2=1.28\)。越靠近谷底斜率越小，步伐自動變小。
  5. η = 1 會怎樣：\(w=2-1\times4=-2\)；下一步斜率 \(-4\)，\(w=-2-1\times(-4)=2\)。在 2 和 −2 之間來回跳，永遠到不了 0。 學習率太大 → 一步跨過谷底跳到對面。再大一點（例如 η = 1.5）每次會跳得更遠，就是「發散」。
  6. η = 0.01 會怎樣：第 1 步只到 \(2-0.04=1.96\)，方向對但很慢，要走非常多步。學習率要「剛剛好」。

梯度下降與優化器比較

損失曲線 \(L(w)=0.1w^4-w^2+0.9w\) 有兩個谷：左邊是全域最小值，右邊是局部最小值。從右側出發，比較不同學習率與優化器能不能到達左邊的谷底。補充曲線為自訂的示範函數。

試試看：① GD、η=0.05 從 w₀=3 出發 → 卡在右邊的局部最小值　② η 調到 0.01 → 要走很多步　③ η 調到 0.5 → 來回震盪、停不下來；0.8 → 發散　④ 換成 Momentum（η=0.05）→ 靠慣性衝過小山丘，到達全域最小值　⑤ 換成 SGD（雜訊 6）→ 多按幾次執行，大多數時候會被雜訊「震」出局部最小值

2.10 優化器（Optimizer）

  • 隨機梯度下降（Stochastic Gradient Descent, SGD）：每次只用一筆或一個 batch 的資料計算梯度；訓練較快，但更新會波動、收斂不穩；這種不穩定反而可能幫助模型跳出局部最小值（local minima）
  • 自適應梯度（Adaptive Moment Estimation, Adam）：結合動量（Momentum）與 RMSProp 的優點；用動量調整更新方向，同時自適應地調整學習率
  • RMSProp：依每個參數最近幾次「平方梯度均值」調整學習率。梯度變化大 → 降低學習率，避免步伐太大；梯度變化小 → 相對增大學習率，加速收斂

👉 優化器的互動比較在 2.9 的梯度下降元件。

2.11 標籤編碼與評估指標

  • 標籤編碼（Label Encoding，密集表示）：類別轉成 0, 1, 2…，需注意虛假順序問題
  • 獨熱編碼（One-Hot Encoding，稀疏表示）：每類一個維度，需注意維度爆炸問題
  • 評估指標（Metrics）：通常使用準確率（Accuracy），另有精確率（Precision）與召回率（Recall）

Label Encoding vs One-Hot Encoding

輸入類別名稱（用逗號分隔），看兩種編碼的結果與向量長度。

公式：評估指標

講義以文字定義，公式為 補充

$$\text{Precision}=\frac{TP}{TP+FP},\qquad \text{Recall}=\frac{TP}{TP+FN},\qquad \text{Accuracy}=\frac{TP+TN}{TP+TN+FP+FN}$$

TP：正確判為正（True Positive）；FP：誤判為正（False Positive）；FN：漏判（False Negative）；TN：正確判為負（True Negative）。

逐步展開：TP = 40、FP = 10、FN = 20、TN = 30

  1. 先讀名字：第二個字母是「模型說的」（P 判正、N 判負），第一個字母是「說得對不對」（T 對、F 錯）。FN = 判負但判錯 = 其實是正的，被漏掉了。
  2. Precision（判為正的裡面，幾個真的是正）：分母是所有「判為正」\(=TP+FP=40+10=50\)；\(40\div50=0.8\)
  3. Recall（真的是正的裡面，抓到幾個）：分母是所有「實際為正」\(=TP+FN=40+20=60\)；\(40\div60\approx0.667\)
  4. Accuracy（全部裡面答對幾個）：答對 \(=TP+TN=70\)；全部 \(=100\)；\(70\div100=0.7\)
  5. 記法：三個分子都有 TP（或 TP＋TN），差在分母：Precision 看「預測那一欄」、Recall 看「實際那一列」。

3. 關鍵名詞表

名詞（中／英）定義一句話直覺解釋
像素（Pixel）影像最小單位，值介於 0～255圖片裡的一個小格子
頻道（Channel）影像的顏色分量，RGB 有 3 個、灰階有 1 個疊在一起的幾張單色底片
支持向量機（SVM）找最佳超平面並最大化間隔的分類器在兩群點中間畫一條「最寬的馬路」
間隔（Margin）資料點到超平面的距離馬路的寬度，越寬越安全
核技巧（Kernel Trick）把資料投影到更高維空間，讓原本線性不可分的資料變得可分平面切不開就把資料「抬起來」再切
明氏距離（Minkowski Distance）\(\big(\sum|x_i-y_i|^p\big)^{1/p}\)，\(p=1\) 為曼哈頓、\(p=2\) 為歐幾里得調一個旋鈕 \(p\)，就能在兩種距離之間切換
K 最近鄰（KNN）以最近的 K 個鄰居多數決決定類別近朱者赤，看你身邊多數是誰
主成分分析（PCA）沿變異最大方向投影的線性降維法從最能看出差異的角度拍一張「壓扁」的照片
激活函數（Activation Function）套在節點輸出上的非線性函數讓網路能學「彎曲」的關係
Sigmoid把實數壓到 0～1，用於二元分類輸出輸出「是」的機率
Softmax把多個分數轉成加總為 1 的機率分布，用於多類別分類把各類分數轉成「得票率」
交叉熵（Cross-Entropy）衡量真實分布與預測分布差異的分類損失對正確答案越沒信心，罰得越重
前向傳播（Forward Propagation）資料從輸入層逐層計算到輸出層模型「作答」
反向傳播（Backward Propagation）從損失往回用連鎖律算每個權重的梯度模型「檢討是誰的錯」
梯度下降（Gradient Descent）沿著損失梯度的反方向更新權重往山谷最低點一步步走
學習率（Learning Rate）每次更新權重的步伐大小，屬於超參數下山時每步跨多大
局部最小值（Local Minima）附近最低但不是全域最低的點小坑洞，不是真正的谷底
動量（Momentum）更新時參考過去的更新方向球滾下山會有慣性
精確率（Precision）預測為正的結果中，真的是正的比例「我說是的」有幾成對
召回率（Recall）實際為正的樣本中，被正確找出的比例「該抓的」抓到幾成
超參數（Hyperparameter）訓練前由人設定、不會被學習的設定值訓練的「遊戲規則」

6. 常見觀念陷阱

  • 二元分類用 Sigmoid、多類別用 Softmax，不要弄反。
  • 分類用交叉熵，迴歸用 MSE 或 MAE。
  • SGD 的「不穩定」不完全是壞事：波動可以幫助跳出局部最小值。
  • Adam = Momentum ＋ RMSProp，考試常問「Adam 結合了哪兩者」。
  • RMSProp 的方向：梯度變化大 → 學習率變小；梯度變化小 → 學習率變大。
  • 學習率是超參數，不是參數：它由人設定，不會被模型學習。
  • KNN 的 K 設奇數是為了避免投票平手（二元分類時最有效 補充）。
  • 歐幾里得 vs 曼哈頓：高維時曼哈頓較穩健，因為歐幾里得的平方會放大少數大差異維度的影響。
  • PCA 是線性降維，對非線性結構無效；KNN、SVM（不加 kernel）也都有非線性的限制。
  • 講義在 PCA 圖像降維中以「改用灰階圖」為例；補充單純的彩色轉灰階是固定加權公式，不等於對資料執行 PCA，兩者都是「降維」的概念但做法不同。
  • Label Encoding 有虛假順序、One-Hot 有維度爆炸，不要記反。
  • Precision vs Recall：Precision 的分母是「預測為正」，Recall 的分母是「實際為正」。

7. 自我測驗

1.（選擇）Adam 優化器結合了哪兩種方法的優點？

(B)。Adam 用動量調整更新方向，用 RMSProp 的想法自適應調整學習率。

2.（選擇）要辨識一張圖是貓、狗或鳥，輸出層與損失函數最適合的組合是？

(B)。三類是多類別分類，輸出層用 Softmax；分類任務用交叉熵。MSE／MAE 用於迴歸，ReLU 不是分類輸出層函數。

3.（簡答）請列出 KNN 的兩個缺點，並說明為什麼它不適合直接拿來處理高解析度圖片。

看解答
① 計算效率低：預測時要與所有樣本算距離；② 高維表現不佳：高維空間中距離失去意義；③ 無法處理非線性關係。高解析度圖片的維度極高（例如 224×224×3 = 150,528 維），距離計算又慢又不可靠。

4.（計算）點 P(6, 2) 與 Q(4, 4) 到原點的歐幾里得距離與曼哈頓距離各是多少？

看解答
歐幾里得：\(d(P)=\sqrt{36+4}=\sqrt{40}\approx6.32\)，\(d(Q)=\sqrt{16+16}=\sqrt{32}\approx5.66\)；曼哈頓：\(d(P)=6+2=8\)，\(d(Q)=4+4=8\)。歐幾里得認為 P 較遠（被 x 軸的 6 主導），曼哈頓認為兩者一樣遠。可以在 4.1 的元件把 B、C 設成 P、Q 驗算。

5.（計算）某分類器 TP=30、FP=20、FN=10、TN=40，請計算 Precision、Recall、Accuracy。

看解答
Precision = 30/(30+20) = 0.6；Recall = 30/(30+10) = 0.75；Accuracy = (30+40)/100 = 0.7。
