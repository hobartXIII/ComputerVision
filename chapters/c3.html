📈 模型品質與改進

📖 故事版：第 3 集：小視的期末評鑑

場景 1｜背答案不算會

小視把練習題背得滾瓜爛熟，每次都考滿分。阿明卻換了一批它沒看過的新照片，分數馬上掉下來。阿明說：「背答案不算會。要知道你是不是真的會，得用你沒看過的題目考。」

他把資料分成三份：

  • 訓練集（Training Set）是課本，唯一拿來更新權重的資料。
  • 驗證集（Validation Set）是模擬考。不更新權重，每個 epoch 訓練完就考一次，用來調超參數、挑最好的模型、判斷是不是開始背答案、決定什麼時候停。
  • 測試集（Test Set）是正式考卷，模型從沒看過，等訓練全部結束才打開，只考一次。

小視想偷懶：「如果我拿正式考卷來調學習率，調到分數最高，不是更好嗎？」阿明搖頭：「那等於先看過考卷再考試，分數會過度樂觀，代表不了你在真實世界的表現。」小視記下流程：每個 epoch 先在 Train 上更新權重，再到 Val 算 loss 和 accuracy；重複 n 個 epoch，最後才在 Test 上算一次。

場景 2｜一個分數看不出哪裡錯

小視在手寫數字測驗拿到 9,873／10,000，也就是 98.73%。阿明問：「你最常把哪個數字認錯？是不是常把 8 看成 3？」小視答不出來，因為 Accuracy 只有一個數字。

阿明畫了一張 10×10 的混淆矩陣（Confusion Matrix）：列是真實的數字、欄是預測的數字，對角線是答對的，其他格子是答錯的。小視一眼就找到最大的兩格：4 被判成 9 有 9 次，7 被判成 2 有 7 次。「原來我最弱的是 4 和 7。」

阿明再給它一份分類報告（Classification Report）：每個數字各自的 Precision、Recall、F1，以及 Support（這個類別在資料中出現幾次）。小視判斷：要找「哪一類最差」，看分類報告；要找「把誰誤認成誰」，看混淆矩陣。

場景 3｜95 分的陷阱

這次的任務是從照片篩出生病的果樹。小視交出 95% 的 Accuracy，很得意。阿明卻發現：果園裡病樹本來就只有 5%，小視把每一棵都說成健康，就能拿到 95 分，可是一棵病樹都沒抓到。小視第一次明白：類別不平衡時，Accuracy 不夠用。

阿明把二元分類的混淆矩陣縮成 2×2：真陽性（TP）是病樹、也判成病樹；偽陰性（FN）是病樹、卻判成健康；偽陽性（FP）是健康、卻判成病樹；真陰性（TN）是健康、也判成健康。小視背下讀法：第二個字母是「模型說的」，第一個字母是「說得對不對」。

場景 4｜同一張表，五種角度

小視改進模型後重新篩檢，數字剛好和課本的 COVID 例子一樣：TP = 90、FN = 10、FP = 5、TN = 40，共 145 棵。阿明教它先把四個小計算好：實際生病 100、實際健康 45、判成生病 95、全部 145，「每個指標都是某一格除以某個小計，分母不會搞錯」。

  • Accuracy：\((90+40)\div145\approx0.897\)；錯誤率約 0.103。
  • 召回率（Recall），又叫敏感度（Sensitivity）、TPR：100 棵病樹抓到幾棵？\(90\div100=0.9\)。
  • FPR：45 棵健康的樹，被冤枉的比例 \(5\div45\approx0.111\)。
  • 特異度（Specificity），又叫 TNR：健康的樹被正確放過的比例 \(40\div45\approx0.889\)，剛好等於 \(1-\text{FPR}\)。
  • 精確率（Precision）：說是病樹的 95 棵裡，真的生病的比例 \(90\div95\approx0.947\)。

場景 5｜該看哪一個指標

阿明給了小視三種情況，要它判斷該重視哪個指標：

  • 「病樹會傳染整片果園，漏掉一棵就麻煩了。」小視：「最怕漏掉，看 Recall。就像 COVID 篩檢，寧可多抽幾個人去複檢，也不要漏掉真的病人。」
  • 「判成病樹就會直接砍掉。」小視：「最怕冤枉健康的樹，看 Precision。」
  • 「兩種錯誤都很麻煩。」小視：「看 F1。」

小視本來想直接把 Precision 和 Recall 平均。阿明舉了一個例子：Precision 1、Recall 0.1，也就是只抓到一成病樹。算術平均是 0.55，看起來還行；F1 是 \(\frac{2\times1\times0.1}{1+0.1}\approx0.18\)，直接反映出「有一項很爛」。F1 是兩者的調和平均，兩邊都要顧到才會高。這次篩檢的 F1 是 \(\frac{2\times0.947\times0.9}{0.947+0.9}\approx0.923\)。

小視又發現兩者通常此消彼長：把判斷門檻調低，只要有一點像病樹就報，Recall（TPR）會上升，但 FPR 也跟著上升，健康的樹被冤枉的變多。要在兩者之間取捨，取決於哪一種錯誤的代價比較高。

場景 6｜從兩條曲線判斷病因

接著阿明處理背答案的毛病。他把小視訓練時的兩條曲線畫出來：訓練誤差一直往下降，驗證誤差降到一半卻開始往上升。阿明說：「這就是過度擬合（Overfitting）：在訓練資料上表現很好，在沒看過的資料上表現很差，也就是泛化（Generalization）能力變差了。」

小視學會看曲線判斷：

  • 訓練誤差和驗證誤差都很高 → 連課本都沒學會，是擬合不足（Underfitting）。
  • 訓練誤差很低、驗證誤差開始上升 → 背答案，是 Overfitting。
  • 兩條都低、而且很接近 → 泛化良好。

阿明舉了幾個背錯東西的例子。有個模型把所有紅色的東西都判成「消防車」，因為它學到的是顏色，不是消防車真正的特徵。四張狗的照片背景都是草地，模型如果學到的是「草」，一張只有草地的照片也會被判成狗。還有一張拼圖：捲毛的棕色小狗和貼上塑膠眼睛的炸雞交錯排列，顏色紋理幾乎一樣，連人都會搞混。只靠表面特徵的模型很容易被騙。

過度擬合常見的原因有三個：訓練資料太少、用了太多特徵、模型太複雜。阿明說：「最簡單的解法是增加訓練資料或降低模型複雜度。如果還不夠，就用正則化（Regularization），逼模型學對的特徵，例如狗的尾巴、鼻子、耳朵，而不是背景的樹和草。」

場景 7｜第一帖藥：L1 與 L2

第一帖藥是在 Loss 加上權重的懲罰（Penalty），強度由 \(\lambda\) 控制。L1（Lasso）加的是權重絕對值的總和，L2（Ridge）加的是權重平方的總和。目的都是讓模型用小一點的權重，不讓少數節點有過大的影響。

小視拿權重 \((3,\ -0.1,\ 0)\)、\(\lambda=0.01\) 試算：L1 penalty 是 \(0.01\times3.1=0.031\)，L2 是 \(0.01\times9.01=0.0901\)。它發現 L2 的 0.09 幾乎全來自大權重 3。

阿明問：「那兩者推權重的方式哪裡不同？」小視算推力（penalty 的斜率）：L1 對每個權重的推力都是 0.01，不管大小，小權重很快就被推到 0；L2 的推力是 \(2\lambda w\)，\(w=3\) 被推 0.06，\(w=0.1\) 只被推 0.002，越接近 0 越推不動。結論：L1 會把不重要特徵的權重降為 0，有特徵選取的效果；L2 讓所有權重一起變小，大的縮最多。

小視判斷要用哪一個：想知道哪些特徵根本沒用、把它們刪掉 → L1；只是想讓整個模型平滑一點 → L2。阿明補一句：「\(\lambda\) 不能太大，權重被壓得太小，模型就學不到東西，變成 underfitting。」

場景 8｜第二帖藥：Dropout

第二帖藥是 Dropout。小視發現自己的網路裡有幾個「學霸神經元」，大部分的判斷都靠它們。Dropout 的做法是：每個 mini-batch 隨機關掉一層裡的一些節點（例如一半，由 Dropout Rate 控制），前向、反向傳播後只更新開著的節點；下一個 mini-batch 再重新隨機關一批。

學霸不一定在場，其他神經元只好也學會判斷，模型因此學到更可靠的特徵，效果就像把很多個子網路平均起來。小視問：「考試的時候也要關嗎？」阿明說：「測試時全部打開。」代價是收斂變慢，所以用 Dropout 時要多給一些 epoch。

場景 9｜第三帖藥：在最好的時候停下來

第三帖藥是提早停止（Early Stopping）。小視不知道該訓練幾個 epoch，阿明教它設一個耐心值 P：驗證誤差連續 P 個 epoch 都沒有更好，就停；每個 epoch 都存一次權重。

小視用 P = 3 實際跑一次，驗證損失依序是 0.50、0.40、0.35、0.36、0.37、0.38。第 3 個 epoch 是最低的 0.35，之後連續 3 次沒有進步，在第 6 個 epoch 停下來。小視本來想直接用第 6 個 epoch 的權重，阿明提醒：「停下來的時候已經多練了 3 個 epoch，要取回第 3 個 epoch 存的權重。」

P 要怎麼選？小視判斷：P 太小，一兩次小波動就會誤判而太早停；P 太大，又會浪費訓練時間。

場景 10｜第四帖藥：把每一層拉回同一個起跑線

第四帖藥是批次正規化（Batch Normalization, BN）。小視發現，深層的輸入分布一直在漂移，因為前面每一層的權重都在變。BN 對每個 mini-batch 算平均和標準差，把數值拉回平均 0、變異 1 附近，再用兩個可學習的參數 \(\gamma\)（縮放）、\(\beta\)（平移）調成這一層最適合的分布。

小視用 batch \((2,4,6,8)\)、\(\gamma=2\)、\(\beta=1\) 算一次：平均 5、變異數 5、標準差約 2.236，標準化後是 \((-1.342,\ -0.447,\ 0.447,\ 1.342)\)，再乘 2 加 1，得到 \((-1.683,\ 0.106,\ 1.894,\ 3.683)\)。

BN 通常放在卷積層和激活函數之間，控制進入非線性函數的數值，避免落進 Sigmoid／tanh 的飽和區。效果是訓練更穩、可以用比較大的學習率、收斂比較快，也帶一點正則化效果。

阿明問：「推論時一次只來一張照片，batch 平均怎麼算？」小視想了想：「算不出來，而且同一張照片跟不同照片一起進來，結果還會不一樣。」所以推論時改用訓練中用移動平均累積的 running mean 和 running std。momentum 0.9、從 0 開始，第一個 batch 平均 5，running mean 變成 0.5；第二個 batch 平均 4，變成 \(0.9\times0.5+0.1\times4=0.85\)，慢慢靠近真正的平均。小視也算了參數量：接在 32 片濾波器後面的 BN，有 \(2\times32=64\) 個可學習參數（running mean／var 不算）。

場景 11｜吃藥的順序

小視想一口氣把四帖藥全吃下去。阿明攔住它：「先建立 Baseline Model，看看不加正則化的表現，再一帖一帖加。參數設錯的話，正則化反而會讓模型變差。很簡單的模型，也不太需要正則化。」小視照做，每加一帖就看一次驗證曲線，確認真的有改善。

場景 12｜一張變很多張

最後一招是治本的。既然過度擬合的原因之一是資料太少，那就增加資料。資料擴增（Data Augmentation）把照片翻轉、旋轉、縮放、裁切、扭曲、調亮度和對比，一張變很多張。它發生在 Data Loader 搬資料的時候，每次讓模型看到不同版本的圖片，而且只對訓練資料做。

小視本來想全部的變換都開到最大。阿明問：「果樹的照片上下顛倒合理嗎？」小視想了想：「實際拍照不會拍到倒過來的樹，模型學那個沒有用。」它判斷：擴增出來的圖，要是現實中可能出現的樣子。左右翻轉、亮度變化、稍微旋轉都很合理。

阿明又介紹幾種進階方法。遮擋類的 CutOut、Random Erasing 故意蓋掉一塊，逼模型不要只看最明顯的地方；混合類的 MixUp 把兩張圖按比例疊在一起，例如狗 0.7、貓 0.3，標籤也變成 (0.7, 0.3)；CutMix 則把一塊 16×16 的貓圖貼到 32×32 的狗圖上，面積佔 \(256\div1{,}024=0.25\)，所以標籤是狗 0.75、貓 0.25。小視注意到：邊長是一半，面積卻是四分之一。組合類還有 Copy-Paste 和 Mosaic。

最後兩種更聰明：自適應（Adaptive）擴增會依訓練中的 loss 和梯度回饋，把擴增參數往讓 loss 變大的方向調，讓樣本一直保持適當的挑戰性；針對性資料生成（TDG）則不平均增加資料，而是先找出模型容易誤判的子群，再專門為它們生成樣本。小視就這樣看過各種「換了角度的蘋果」，不再只認得課本上那一顆。

評鑑通過了。阿明說：「現在你會看、也會自我檢查。接下來，去看看前輩們都怎麼蓋更厲害的眼睛。」（→ C4）

小視的筆記本｜本集學到的判斷法

  • 資料分工：Train 更新權重；Val 調超參數、決定何時停；Test 最後只用一次，不能拿來調。
  • 類別不平衡：不要只看 Accuracy。怕漏抓 → Recall；怕誤報 → Precision；兩者都要 → F1（調和平均）。
  • 看曲線判斷病因：兩條都高 → Underfitting；訓練低、驗證上升 → Overfitting。
  • 選正則化：想刪掉沒用的特徵 → L1；整體縮小權重 → L2；不依賴少數節點 → Dropout；不知道訓練幾輪 → Early Stopping（取回最佳權重）；訓練不穩 → BN。
  • 順序：先建 Baseline，再一項一項加；\(\lambda\) 太大會 Underfitting。
  • 選擴增：只做在訓練資料上，而且要是現實中可能出現的樣子。

資料集與評估（2.1～2.4）

⭐ Q1. Training、Validation、Test 資料集各自扮演什麼角色？
  • Training set：讓模型學習參數，每個 epoch 用梯度下降與反向傳播更新權重。
  • Validation set：訓練期間公正評估模型（每個 epoch 結束算 loss 與 accuracy），用來調整超參數、挑選最佳模型、判斷 overfitting 或 Early Stopping，不用來更新權重。
  • Test set：模型從未看過的資料，訓練全部結束後只用一次，評估最終的泛化能力。

注意：Test 不能拿來調模型，否則評估結果會過度樂觀。

💬 白話：Training 是課本、Validation 是模擬考、Test 是正式考試；正式考試只考一次，不能考完再回去改。

🔢 例子 補充：10,000 張圖分成 7,000 張訓練、1,500 張驗證、1,500 張測試。

Q2. Loss 和 Accuracy 曲線怎麼看？為什麼還需要混淆矩陣（Confusion Matrix）？
  • Training loss 一直下降、Validation loss 卻開始上升（或兩者 Accuracy 差距拉大）→ 開始 overfitting。
  • Accuracy 只有一個數字，看不出模型在每個類別的對錯。混淆矩陣列出「真實 vs 預測」的每一格，能找出表現較差的類別、容易把誰誤認成誰（例：MNIST 的 4 常被判成 9）。
⭐ Q3. Precision、Recall、Accuracy 各代表什麼意義？
  • Accuracy：所有樣本中預測正確的比例 \(\dfrac{TP+TN}{TP+TN+FP+FN}\)。
  • Precision：被預測為正的樣本中真的是正的比例（預測為陽性的可信度）\(\dfrac{TP}{TP+FP}\)。
  • Recall（＝ Sensitivity、TPR）：實際為正的樣本中被正確找出的比例（有沒有漏抓）\(\dfrac{TP}{TP+FN}\)。

類別不平衡時 Accuracy 可能很高但模型不好，要搭配 Precision 與 Recall；兩者通常有取捨，例如疾病篩檢重視 Recall，避免漏掉病人。F1 是兩者的調和平均。

講義 COVID 例：TP=90、FN=10、FP=5、TN=40 → Accuracy ≈ 0.897、Precision ≈ 0.947、Recall = 0.9。

Overfitting 與正則化（2.5～2.10）

Q4. 什麼是過度擬合（Overfitting）？怎麼改善？

模型在訓練資料表現很好，在新資料表現很差：把訓練資料的雜訊和細節也背起來，泛化能力差。

改善：增加資料（含資料擴增）、降低模型複雜度、正則化（L1／L2、Dropout、Early Stopping、Batch Normalization）。

💬 白話：就像只背考古題：考古題全對，換一份新題目就不會了。

🔢 例子 補充：訓練準確率 99%、測試準確率只有 70%，差距很大 → Overfitting。

⭐ Q5. L1 與 L2 正則化的主要差異是什麼？

兩者都在 Loss 加上 Penalty，迫使模型使用較小的權重，強度由 \(\lambda\) 控制：

$$L_{L1}=L+\lambda\sum_j|\theta_j|,\qquad L_{L2}=L+\lambda\sum_j\theta_j^2$$
L1（Lasso）L2（Ridge）
Penalty權重絕對值總和權重平方總和
效果優先把不重要特徵的權重降為 0把所有權重一起變小，大權重罰更重
結果稀疏，有特徵選取效果權重小而平滑，避免少數節點主導

共同注意：\(\lambda\) 太大，權重被壓得過小，會 Underfitting。

💬 白話：L1 像「用一個權重就扣一份錢」，不重要的乾脆不用（變 0）；L2 像「權重越大扣越多」，大家都變小但不會歸零。

🔢 例子：權重 (3, −0.1, 0)、λ = 0.01：L1 懲罰 = 0.01 × (3 + 0.1 + 0) = 0.031；L2 懲罰 = 0.01 × (9 + 0.01 + 0) = 0.0901。大權重 3 在 L2 被平方後懲罰特別重。

⭐ Q6. Dropout 是什麼技術？運作原理？為什麼有助於提升表現？

Dropout 是正則化（Regularization）技術，用來防止 Overfitting。

  1. 訓練時，每個 mini-batch 隨機關閉某一層的部分節點（比例由 Dropout Rate 控制，例如 0.5）。
  2. 前向與反向傳遞只經過開著的節點，也只更新它們的權重。
  3. 下一個 mini-batch 恢復所有節點，再重新隨機關閉一批。
  4. 測試（推論）時不關閉，使用所有節點。

為什麼有效：每次訓練的都是不同的子網路，模型不能依賴少數特定節點，被迫學到更可靠、更具代表性的特徵，泛化較好（效果類似許多子網路的集成 補充）。代價：收斂較慢，要搭配更多 epoch。

💬 白話：每次練習隨機讓一半的隊員休息，整隊就不能只靠某幾個王牌。

🔢 例子：某層有 6 個節點、Dropout Rate 0.5 → 每個 mini-batch 隨機關掉 3 個，下一個 mini-batch 換另一批；測試時 6 個全開。

Q7. Early Stopping 怎麼運作？

每個 epoch 看 Validation loss，連續 P 個 epoch（patience）沒有進步就停止訓練，並取回 Validation loss 最低那一輪的權重。好處是不用事先決定 epoch 數、在 overfitting 之前停下。

例：P = 3，Val loss 0.50 / 0.40 / 0.35 / 0.36 / 0.37 / 0.38 → 第 6 個 epoch 停，取回第 3 個 epoch 的權重。

Q8. Batch Normalization（BN）在做什麼？訓練和推論有什麼不同？
  • 對每個 mini-batch 計算 mean 與標準差並標準化，再用可學習的 \(\gamma\)（縮放）、\(\beta\)（平移）做 \(y=\gamma\hat{x}+\beta\)。CNN 中每個 channel 各有一組。
  • 通常放在 Conv 與 Activation 之間，穩定每一層輸入的分布（緩解 Internal Covariate Shift）。
  • 效果：訓練更穩定、可以用較大的學習率、收斂較快，也有輕微的正則化效果。
  • 訓練時用當下 batch 的統計量；推論時改用訓練中以移動平均累積的 running mean／running STD（推論時 batch 可能只有一張）。

💬 白話：先把每一批資料「拉回平均 0、標準差 1」，再讓模型自己學要不要放大或移動。

🔢 例子：一個 batch 為 (2, 4, 6, 8)：平均 5、標準差約 2.236 → 標準化 x̂ ≈ (−1.342, −0.447, 0.447, 1.342)；γ = 2、β = 1 → y ≈ (−1.683, 0.106, 1.894, 3.683)。

資料擴增（2.11）

Q9. 資料擴增（Data Augmentation）為什麼有用？基本方法有哪些？

Overfitting 的原因之一是訓練資料不夠；資料擴增對訓練資料做變換，增加資料的多樣性，等於讓模型每次看到不同版本的圖片，減少 overfitting、提升泛化。

基本方法：翻轉、亮度與對比、旋轉、縮放、裁切、扭曲。一般只對訓練資料做，通常在 Data Loader 搬資料時即時產生。

💬 白話：同一張照片翻一翻、轉一轉、調亮一點，對模型來說就像多了好幾張新照片。

🔢 例子 補充：1,000 張訓練圖，每張每個 epoch 隨機做翻轉＋旋轉＋亮度調整，模型每次看到的都是不同版本，相當於看過遠多於 1,000 張的變化。

Q10. 遮擋類：CutOut、Random Erasing、Hide-and-Seek、GridMask 差在哪？

共同目的：遮住一部分，強迫模型用多個特徵判斷，不只盯著最明顯的地方。

  • CutOut：遮住一塊固定大小的正方形，填 0（黑色）。
  • Random Erasing：矩形的長寬比與面積都隨機，填隨機數值，比 CutOut 更多變化。
  • Hide-and-Seek：切成 S×S 網格，每格依機率獨立遮掉；主要區域被遮時會學次要區域，但可能一次遮太多或太少。
  • GridMask：規律、等間距的網格遮擋，平衡「過度保留」與「過度刪除」。
Q11. 混合類 MixUp、CutMix，組合類 Copy-Paste、Mosaic 各怎麼做？
  • MixUp：兩張圖整張線性混合，標籤也按比例混合。例：\(\lambda=0.7\) → 標籤「狗 0.7、貓 0.3」。
  • CutMix：A 圖挖一塊換成 B 圖，標籤依面積比例混合。例：32×32 貼 16×16 → B 佔 0.25。
  • Copy-Paste：把物件連同 mask 貼到另一張圖，可同步更新 mask、bbox。
  • Mosaic：多張（常見 4 張）拼成一張，一張圖就看到不同背景、尺度、位置。
Q12. Adaptive Data Augmentation 和 Targeted Data Generation 是什麼？
  • Adaptive Data Augmentation：依訓練中的 loss／梯度回饋，動態調整擴增的種類與強度，讓樣本維持適當的挑戰性（擴增參數往讓 loss 變大的方向更新）。
  • Targeted Data Generation（TDG）：不是平均增加資料，而是找出模型容易誤判的子群（subgroup），針對它生成標註正確的合成樣本，把資料花在模型的弱點上。

💬 白話：Adaptive 是「模型覺得太簡單就加難度」；TDG 是「哪裡常錯就專門多練那裡」。

🔢 例子 補充：模型在「夜間拍的貓」常判錯，TDG 就專門生成一批標註正確的夜間貓圖補進訓練資料。

2. 章節大綱

2.1 Training、Validation、Test 資料集

🎯 目的：把資料分成 Training、Validation、Test，分別用來學習、調整與最終評估。

✅ 效果：能公正地評估模型、及早發現 overfitting；最後的 Test 結果代表真正的泛化能力。

  • Training data：模型用來學習參數
  • Validation data：訓練期間用來對模型做公正評估（每個 epoch 訓練完就評估一次）
  • Test data：最終測試模型效能的資料集，模型從未看過（例如 Kaggle 競賽的私有測試集）
  • 「Validation」與「Test」常常被混用
  • 補充三者的分工：
    • Training：唯一用來更新權重的資料
    • Validation：不更新權重，用來調整超參數、挑選最佳模型、判斷是否 overfitting 或該不該 Early Stopping（見 2.8）
    • Test：訓練全部結束後只用一次，評估最終的泛化能力；不能拿來調模型，否則評估結果會過度樂觀
  • 流程：每個 epoch 先用梯度下降與反向傳播在 Train 上更新權重 → 在 Val 上算 loss 與 accuracy → 重複 n 個 epoch → 最後才在 Test 上算一次
  • 基本評估指標：Training Loss、Training Accuracy、Test／Validation Loss、Test／Validation Accuracy

2.2 Accuracy 不夠用：混淆矩陣

🎯 目的：看出模型在每個類別的對錯，以及容易把誰誤認成誰。

✅ 效果：找出表現較差的類別（例如 4 容易被判成 9），補足 Accuracy 只有一個數字的不足。

  • 問題情境：模型分不出「3」和「8」。怎麼找出這種問題？哪個類別表現較差？模型是不是傾向把 8 判成 3？單一個 Accuracy 數字回答不了這些問題
  • 混淆矩陣：列為真實類別、欄為預測類別 補充這是慣例，有些工具相反。對角線（綠色）是預測正確、其他格（紅色）是預測錯誤
  • 講義 MNIST 例子：4 容易被預測為 9、7 容易被預測為 2

MNIST 混淆矩陣與分類報告

講義「MNIST Confusion Matrix Example」頁的原始數字：每列是真實數字，每行是模型預測；每列總和就是 MNIST 測試集各數字的張數。點任一格看它代表什麼，下方的分類報告（由矩陣算出，與講義的 Classification Report 頁相同）會同步標示該類別。

2.3 二元分類指標（COVID 例子）

🎯 目的：從混淆矩陣的不同角度衡量分類器（Accuracy、Recall、Precision、Specificity、FPR）。

✅ 效果：可以依應用選指標，例如疾病篩檢重視 Recall，避免漏掉病人。

  • 準確率（Accuracy）、錯誤率（Misclassification／Error Rate）
  • 真陽性率（True Positive Rate, TPR）＝ 敏感度（Sensitivity）＝ 召回率（Recall）：患有 COVID 的病人中，我們預測出了多少
  • 偽陽性率（False Positive Rate, FPR）：沒有 COVID 的人中，被誤判有 COVID 的比例
  • 真陰性率（True Negative Rate, TNR）＝ 特異度（Specificity）：沒有 COVID 的人中，正確判定的比例
  • 精確率（Precision）：預測有 COVID 的人中，真的有的比例
  • 數值計算見 2.3 的計算器

公式：二元分類指標

$$\text{Accuracy}=\frac{TP+TN}{\text{Total}},\quad \text{Error Rate}=1-\text{Accuracy},\quad \text{Recall (TPR)}=\frac{TP}{TP+FN}$$ $$\text{FPR}=\frac{FP}{FP+TN},\quad \text{Specificity (TNR)}=\frac{TN}{FP+TN},\quad \text{Precision}=\frac{TP}{TP+FP},\quad F_1=\frac{2\cdot\text{Precision}\cdot\text{Recall}}{\text{Precision}+\text{Recall}}$$

TP：有病且判有病；FN：有病卻判沒病；FP：沒病卻判有病；TN：沒病且判沒病。補充F1 公式（講義只寫「調和平均數」）。

🔁 後續用途 補充

  • 依應用選指標：疾病篩檢重 Recall（不能漏）、垃圾郵件過濾重 Precision（不能誤殺），F1 兩者兼顧。
  • 搭配判斷門檻：門檻往下調 → TPR 上升但 FPR 也上升，要在兩者間取捨（本章的門檻元件）。
  • 比較不同模型、或同一模型改進前後的效果，都要用同一組指標。

逐步展開：講義 COVID 例子（TP 90、FN 10、FP 5、TN 40）

  1. 先算四個小計：實際有病 \(TP+FN=100\)；實際沒病 \(FP+TN=45\)；預測有病 \(TP+FP=95\)；全部 145。 每個指標都是「某一格 ÷ 某個小計」，先把小計算好就不會搞錯分母。
  2. Accuracy：答對的是 TP 和 TN：\((90+40)\div145=130\div145\approx0.897\)；Error Rate \(=1-0.897=0.103\)
  3. Recall（＝ Sensitivity ＝ TPR）：100 個病人抓到幾個？\(90\div100=0.9\)
  4. FPR：45 個沒病的人裡，幾個被誤判有病？\(5\div45\approx0.111\)
  5. Specificity（TNR）：45 個沒病的人裡，幾個被正確判為沒病？\(40\div45\approx0.889\)；也等於 \(1-\text{FPR}\)。
  6. Precision：模型說有病的 95 人裡，幾個真的有？\(90\div95\approx0.947\)
  7. F1：\(\dfrac{2\times0.947\times0.9}{0.947+0.9}=\dfrac{1.705}{1.847}\approx0.923\)
  8. 為什麼 F1 用調和平均 補充：假設 Precision 1、Recall 0.1（只抓到一成病人）。算術平均 \((1+0.1)\div2=0.55\) 看起來還行；F1 \(=\frac{2\times1\times0.1}{1.1}\approx0.18\)，直接反映出「有一項很爛」。

2.4 Precision、Recall、F1 與分類報告

🎯 目的：同時考慮「預測為正的可信度」（Precision）和「有沒有漏抓」（Recall）。

✅ 效果：類別不平衡時比 Accuracy 可靠；F1 用調和平均兼顧兩者，任一個太低 F1 就會很低。

  • 補充類別不平衡時 Accuracy 會失真：例如 100 人只有 5 人有病，模型全部猜「沒病」也有 95% 的 Accuracy，卻一個病人都沒抓到（Recall = 0），所以要搭配 Precision 與 Recall 一起看
  • Precision／Recall 取捨（tradeoff）：通常提升其中一個，另一個就會下降
  • 有時可以犧牲一些 Precision 來換 Recall：例如看診，寧可多抽幾個去複檢，也不要漏掉真的病人
  • F1：Precision 與 Recall 的調和平均數（harmonic mean）
  • 分類報告（Classification Report）：列出每個類別的 Precision、Recall、F1；Support 代表該類別在資料中出現的次數（見上方 MNIST 元件）

門檻值與 Precision／Recall 取捨

補充模型對每個人輸出一個「有 COVID 的分數」，分數 ≥ 門檻就判為陽性。預設門檻 0.5 剛好得到講義的 TP = 90、FN = 10、FP = 5、TN = 40（分數是配合講義數字產生的示意資料）。把門檻往左拉，看 Recall 和 Precision 怎麼變。

2.5 過度擬合與泛化

🎯 目的：認識模型在訓練資料表現好、在新資料表現差的問題與成因。

✅ 效果：知道要用增加資料、降低模型複雜度、正則化等方法提升泛化能力。

  • 過度擬合（Overfitting）：模型在訓練資料上過度訓練，在測試資料上表現很差（很常發生）
  • 常見成因：訓練資料太少、用太多特徵（Features）、模型太複雜
  • 泛化（Generalization）：模型在沒見過的資料上的表現
  • 講義例子：模型把紅色的東西都判成「消防車」，因為它學到的是「用顏色分辨」，而不是消防車真正的特徵
  • 如何避免：
    • 最簡單：增加訓練資料、降低模型複雜度
    • 使用正則化：限制模型複雜度，讓模型學「對的特徵」（例如狗的尾巴、鼻子、耳朵，而不是背景的樹、草）
  • 「如何欺騙模型」：講義放了一張 4×4 的拼圖，捲毛的棕色小狗和貼上塑膠眼睛的炸雞交錯排列，顏色、紋理幾乎一樣，連人一眼看過去都會搞混。只靠顏色、紋理這類表面特徵的模型很容易被騙，所以要讓模型學到真正有區別力的特徵（形狀、五官）。前一頁的例子也是同一件事：四張狗的照片背景都是草地，如果模型學到的是「草」，一張只有草地的照片也會被判成狗

模型複雜度與 Overfitting

補充用多項式擬合 12 個訓練點（實心），另外 40 個測試點（空心）模型沒看過。把「次方」拉高，模型變複雜：訓練誤差一路下降，測試誤差卻在某處開始上升，這就是 overfitting。再把 L2 的 λ 調大，看正則化怎麼把曲線「拉回來」。

2.6 正則化方法一：L1 與 L2

🎯 目的：在 Loss 加上 Penalty，迫使模型使用較小的權重，避免 overfitting。

✅ 效果：L1 把不重要特徵的權重降為 0（特徵選取）；L2 讓所有權重一起變小；λ 太大會 underfitting。

  • 做法：Loss Function ＋ Penalty（L1 或 L2）
  • 目的：迫使模型使用較小的參數（weights 和 biases），避免特定節點產生過大影響
  • L1（L1-Norm、Lasso Regression）：加上權重絕對值的總和
  • L2（Ridge Regression）：加上權重平方的總和
  • 強度由係數 \(\lambda\) 控制，越大 Penalty 越重；L1（又稱 L1-Norm、Lasso Regression）加的是 \(\lambda\sum_{j=1}^{p}\lvert\beta_j\rvert\)，L2（又稱 Ridge Regression）加的是 \(\lambda\sum_{j=1}^{p}\beta_j^2\)，\(\beta_j\) 是模型參數
  • 區別：
    • L1 會優先把不重要特徵的權重降為 0 → 有「特徵選取」的效果
    • L2 會優先把所有權重都減小 → 大的權重會產生更大的 Penalty
  • 總結：兩者都讓模型傾向用小權重，除非大權重能顯著降低原本的 Loss；模型在「較小權重」與「較低原始 Loss」之間取捨，由 \(\lambda\) 控制

公式：L1 與 L2 正則化

$$L_{L1}=L_{\text{original}}+\lambda\sum_{j=1}^{p}\lvert\beta_j\rvert,\qquad L_{L2}=L_{\text{original}}+\lambda\sum_{j=1}^{p}\beta_j^{2}$$

\(\beta_j\)：模型參數（weights and biases，共 \(p\) 個）；\(\lambda\)：控制 Penalty 強度，越大越重。符號與講義相同。

例：權重 \((3,-0.1,0)\)、\(\lambda=0.01\)：L1 penalty \(=0.01\times(3+0.1+0)=0.031\)；L2 penalty \(=0.01\times(9+0.01+0)=0.0901\)。L2 裡大權重 3 貢獻了 0.09、小權重 0.1 幾乎沒影響 → L2 主要壓大權重；L1 對每個權重的「每單位懲罰」一樣，小權重也會被推到 0 補充。

🎯 目的：在損失裡加上「權重大小」的懲罰，不讓模型靠很大的權重硬背訓練資料，藉此降低過擬合。

🔁 後續用途 補充

  • L2（又稱 weight decay）讓權重整體變小、模型比較平滑，是訓練 CNN 的常見設定。
  • L1 會把不重要的權重推到剛好 0，等於自動挑出重要的特徵。
  • \(\lambda\) 是要調的超參數：太大會欠擬合，太小沒效果。C5 的 L2-SP 把「拉向 0」改成「拉向預訓練權重」。

逐步展開：為什麼 L1 會把權重推到 0、L2 不會？補充

  1. 先算 penalty：權重 \((3,-0.1,0)\)。L1：\(|3|+|-0.1|+|0|=3.1\)，\(\times0.01=0.031\)；L2：\(3^2+(-0.1)^2+0^2=9.01\)，\(\times0.01=0.0901\)。
  2. 梯度下降會怎麼推權重：penalty 對權重的斜率，就是每一步額外把權重往 0 推的力道。
  3. L1 的斜率：\(\lambda|w|\) 的斜率是 \(\lambda\times(\pm1)\)，不管 \(w\) 大小都是 \(0.01\)。\(w=3\) 和 \(w=0.1\) 都被推一樣大力 → 小權重很快就被推到 0。
  4. L2 的斜率：\(\lambda w^2\) 的斜率是 \(2\lambda w\)。\(w=3\)：\(2\times0.01\times3=0.06\)；\(w=0.1\)：\(2\times0.01\times0.1=0.002\)。 權重越小推力越小，越接近 0 越推不動，所以 L2 只會讓權重「變小」，很少剛好變 0；大權重則被推得最用力。
  5. 結論：L1 → 很多權重剛好是 0（特徵選取）；L2 → 所有權重一起縮小、大的縮最多。

L1 vs L2：Penalty 與權重怎麼縮

上半：輸入權重和 λ，算出兩種 Penalty（預設是筆記的例子）。下半 補充：假設不加正則化時最佳權重是 \(a\)，加上 Penalty 後最佳權重會變成多少？拉大 λ 比較兩者：L1 把小權重直接歸零，L2 讓所有權重等比例縮小、永遠不會剛好變 0。

2.7 正則化方法二：Dropout

🎯 目的：防止 overfitting：訓練時隨機關閉部分節點。

✅ 效果：模型不能依賴少數節點，學到更可靠的特徵、泛化較好；代價是收斂較慢。

  • 出處：Srivastava et al., “Dropout: a simple way to prevent neural networks from overfitting”, JMLR 2014
  • Dropout 影響的不是訓練損失，而是模型本身
  • 訓練流程：
    1. 隨機關閉某一層的一些節點（例如一半）
    2. 將一個 mini-batch 前向傳遞，用反向傳遞計算梯度
    3. 只更新開著的節點的權重
    4. 恢復所有節點，再隨機關閉一批，處理下一個 mini-batch
  • 用 Dropout Rate 控制關閉的比例
  • 迫使模型學更可靠的特徵（每次等於訓練不一樣的模型）
  • 補充為什麼有效：模型不能依賴少數特定節點，被迫學到更具代表性的特徵，在沒看過的資料上泛化較好；效果類似把許多子網路做集成（ensemble）平均
  • 缺點：會增加模型收斂（converge）所需時間
  • 測試時使用所有節點做預測

Dropout：每個 mini-batch 換一個網路

兩個隱藏層各有 Dropout Rate 比例的節點被隨機關閉（打叉），關掉的節點連線也一起消失，這一輪只更新亮著的權重。按「下一個 mini-batch」重新抽一次；切到「測試」時所有節點都打開。

2.8 正則化方法三：Early Stopping

🎯 目的：在模型開始 overfitting 之前停止訓練。

✅ 效果：不用事先決定 epoch 數，並取回驗證損失最低那一輪的權重。

  • 設定一個門檻：如果接下來 P 個 epoch 都沒有更好的結果就停止訓練
  • 每個 epoch 都儲存模型權重（以便取回最佳的那一個）
  • 互動例子見 2.8

公式：Early Stopping 的例子 補充

若 patience P = 3，Val Loss 依序為 0.50、0.40、0.35、0.36、0.37、0.38 → 第 3 個 epoch 之後連續 3 個 epoch 沒有進步，在第 6 個 epoch 停止，取回第 3 個 epoch 的權重。

🎯 目的：用驗證集損失決定什麼時候該停止訓練，在開始過擬合之前停下來。

🔁 後續用途 補充

  • 不必事先猜要訓練幾個 epoch，訓練到驗證損失不再進步就自動停。
  • 最後取回驗證損失最低那一輪的權重當作模型，而不是最後一輪。
  • patience P 是超參數：太小容易被一兩次波動誤判而太早停，太大則浪費訓練時間。

  3. Epoch 2：0.40 < 0.50，進步 → 最佳 = 0.40，計數歸 0，存檔。
  4. Epoch 3：0.35 < 0.40，進步 → 最佳 = 0.35，計數 0，存檔。

  6. Epoch 5：0.37 → 計數 2。
  7. Epoch 6：0.38 → 計數 3 = P，停止。取回最佳的第 3 個 epoch 權重（0.35）。 停下來的時候已經多訓練了 P 個 epoch，所以一定要取回「之前存的最佳權重」，不是用最後一個。

2.9 正則化方法四：Batch Normalization（BN）

🎯 目的：對每個 mini-batch 標準化，穩定每一層輸入的分布。

✅ 效果：訓練更穩定、可以用較大的學習率、收斂較快，也有輕微的正則化效果。

  • 做法：對每組 mini-batch 分別計算 mean 與標準差（STD）並標準化
  • CNN 中：每一層有 d 個 mean 和 d 個 STD，d 為該層 filter 數量（即 channel 數）
  • 位置：通常放在 Conv Layer 與 Activation Function 之間，控制進入非線性函數的數值分布，避免落入 sigmoid／tanh 的飽和區
    • 這是原始論文與主流做法，但不是唯一答案；部分研究放在 activation 之後也有不錯效果
  • 可學習參數 γ 和 β：
    • 標準化後再做仿射變換 \(y=\gamma\hat{x}+\beta\)，γ 負責縮放、β 負責平移
    • 兩者都透過反向傳播更新（多算 \(\partial L/\partial\gamma\)、\(\partial L/\partial\beta\)），BN 因此從前處理步驟變成模型的一部分
    • 理論上網路可以學到讓輸出還原成標準化前的分布
  • BN 的重點是「穩定」，不是「標準差一定要是 1」：
    • 沒有 BN：進入 activation 的分布由前面所有 conv 層的權重間接交錯決定，訓練中會一直劇烈漂移（內部共變量偏移，Internal Covariate Shift）
    • 有 BN：先標準化，再由這一層自己的 γ、β 直接決定分布；γ、β 經梯度下降緩慢更新，不會劇烈震盪
  • 訓練與推論的差異：
    • 訓練時：mean 與 STD 由當下 mini-batch 即時計算
    • 推論時：batch size 常為 1 或不固定，若仍用當下 batch 統計量，同一筆輸入會得到不同結果，不合理
    • 因此推論時改用 running_mean、running_STD：訓練中用移動平均（Moving Average）累積的估計值，推論時不再更新
    • Moving average：不重算全部歷史，而是用新資料逐步微調既有估計值；常見 momentum 0.9、0.99

公式：Batch Normalization

補充標準化公式；仿射變換與 moving average 為講義內容：

$$\mu_B=\frac{1}{m}\sum_{i=1}^{m}x_i,\quad \sigma_B^2=\frac{1}{m}\sum_{i=1}^{m}(x_i-\mu_B)^2,\quad \hat{x}_i=\frac{x_i-\mu_B}{\sqrt{\sigma_B^2+\epsilon}},\quad y_i=\gamma\hat{x}_i+\beta$$ $$\text{running\_mean}\leftarrow \text{momentum}\times\text{running\_mean}+(1-\text{momentum})\times\text{batch\_mean}$$

\(m\)：mini-batch 大小；\(\epsilon\)：避免除以 0 的極小值；\(\gamma,\beta\)：可學習參數。STD 的更新方式相同。

🎯 目的：把每一層的輸入在 mini-batch 內標準化成平均 0、變異數 1，再用可學習的 \(\gamma\)、\(\beta\) 調回適合的尺度。

🔁 後續用途 補充

  • 訓練更穩定、可以用比較大的學習率、收斂較快，也有輕微的正則化效果。
  • running mean／std 在推論時取代 batch 的統計量（推論時一次可能只有一張圖，算不出 batch 平均）。
  • C5 微調小資料集時，讓 BN 沿用預訓練的統計量，避免小 batch 估得不準。

逐步展開：batch \((2,4,6,8)\)、γ = 2、β = 1（ε 很小，先忽略）

  1. 平均 \(\mu_B\)：\((2+4+6+8)\div4=20\div4=5\)
  2. 每個數減平均：\(2-5=-3\)、\(4-5=-1\)、\(6-5=1\)、\(8-5=3\)
  3. 變異數 \(\sigma_B^2\)：平方再平均：\((9+1+1+9)\div4=20\div4=5\)；標準差 \(\sigma_B=\sqrt5\approx2.236\)
  4. 標準化 \(\hat{x}\)：第 2 步的結果除以 2.236：\(-3\div2.236\approx-1.342\)、\(-1\div2.236\approx-0.447\)、\(0.447\)、\(1.342\)。 現在平均是 0、標準差是 1。
  5. 縮放平移 \(y=\gamma\hat{x}+\beta\)：\(2\times(-1.342)+1=-1.683\)、\(2\times(-0.447)+1=0.106\)、\(2\times0.447+1=1.894\)、\(2\times1.342+1=3.683\)。 γ 把標準差變成 2、β 把平均移到 1。γ、β 是學出來的，網路可以自己決定要什麼分布。
  6. running_mean（momentum 0.9，初始 0）：第 1 個 batch mean 5：\(0.9\times0+0.1\times5=0.5\)；第 2 個 batch mean 4：\(0.9\times0.5+0.1\times4=0.45+0.4=0.85\)。 舊的估計佔 90%、新 batch 佔 10%，慢慢靠近真正的平均。推論時就用這個值。

補充參數量：CNN 中每個 channel 有一組 γ、β，所以接在 32 個 filter 的 conv 後的 BN 有 \(2\times32=64\) 個可學習參數；running_mean／running_var 不是可學習參數。

2.10 正則化小建議

🎯 目的：說明使用正則化時要注意的地方。

✅ 效果：先建立 Baseline 再加正則化，避免參數設錯讓模型變差或 underfitting。

  • 不要一開始就用正則化，先建立 Baseline Model
  • 正則化有時會讓模型變差（例如參數設定錯誤）
  • 用 Dropout 時建議配合更多 epoch，讓模型有足夠時間收斂
  • 很簡單的模型不太需要正則化
  • L2 Penalty 太高 → 權重被壓得過小，模型學不到足夠的 pattern → 擬合不足（Underfitting）（可以在 2.5 的元件把 λ 拉到最大看看）

2.11 資料擴增（Data Augmentation）

🎯 目的：對訓練資料做變換，增加資料的多樣性。

✅ 效果：等於讓模型看到更多不同版本的圖片，減少 overfitting、提升泛化能力。

  • Overfitting 的原因之一是訓練資料不夠，資料擴增可以解決；影像資料特別適合
  • Keras 與 PyTorch 的基本方法：翻轉（水平／垂直）、亮度與對比、旋轉、縮放、裁切、扭曲
  • 一般只對訓練資料做擴增
  • 通常發生在 Data Loader 搬運資料時，等於每次讓模型看不同版本的圖片
  • 進階方法分為五類：
    • 遮擋類（Occlusion-based）：CutOut、Random Erasing、Hide-and-Seek、GridMask
    • 混合類（Mixing-based）：MixUp、CutMix（Torchvision 提供）
    • 組合類（Composition-based）：Copy-Paste（Albumentations）、Mosaic（Ultralytics）
    • 自適應（Adaptive）：依訓練中的 loss／梯度回饋動態調整擴增的種類與強度，讓樣本維持適當挑戰性（arXiv 2207.06658）
    • 針對性資料生成（Targeted Data Generation, TDG）：不是平均增加資料，而是針對模型容易誤判的子群（subgroup）生成標註正確的合成樣本；講義例子是「同時含正負面描述但整體偏正面」的評論（arXiv 2305.17804）
  • Adaptive 頁的流程圖：從資料集取樣 → 抽樣擴增參數 \(O_1\ldots O_N\) → 算出目標模型對這些參數的梯度 \(G_1\ldots G_N\) → 沿梯度方向更新參數 → 再用新的擴增訓練目標模型。圖旁標「梯度上升」：擴增參數是往讓 loss 變大的方向更新，讓樣本越來越難、維持挑戰性（模型本身仍用梯度下降學習）
  • TDG 是講義最後一頁（共 51 頁），內容完整。第二頁的流程圖分兩段：① Automatic Subgroup Discovery：用不同的分群策略把資料分群，挑出「泛化高、干擾低」的分群結果，找出模型表現差的群；② Subgroup Augmentation with LLM：用大型語言模型（論文用 GPT-3）為這些表現差的群生成更多樣本，最後同時看群內準確率與整體準確率

Dropout訓練時隨機關節點，測試時全開學到更可靠的特徵收斂較慢，需要更多 epochFC 層參數多、容易 overfit 的網路
Early StoppingVal 連續 P 個 epoch 沒進步就停簡單、省訓練時間P 太小可能過早停止 補充幾乎所有訓練
Batch Normalization對 mini-batch 標準化 ＋ γ、β穩定各層輸入分布、訓練更穩訓練／推論行為不同，要切換模式深層 CNN

6. 常見觀念陷阱

  • Validation ≠ Test：Validation 在訓練中用來評估與挑模型；Test 只在最後用一次。兩者常被混用，但考試要分清楚。
  • Recall ＝ Sensitivity ＝ TPR，Specificity ＝ TNR，而且 FPR ＝ 1 − Specificity。
  • 分母不要搞錯：Recall、FPR、Specificity 的分母是「實際」有幾個正／負；Precision 的分母是「預測」有幾個正。
  • 醫療篩檢重視 Recall：寧可犧牲 Precision，也不要漏掉病人。
  • F1 是調和平均，不是算術平均：任一個很低，F1 就會很低 補充。
  • L1 讓權重歸零（特徵選取），L2 讓所有權重變小，不要記反。
  • Dropout 只在訓練時作用，測試時用所有節點；它改變的是模型，不是 loss。
  • BN 訓練與推論不同：訓練用當下 batch 的統計量，推論用 running_mean／running_STD。在 PyTorch 中就是 model.train()／model.eval() 的區別 補充。
  • BN 的目的是「穩定」，不是強制平均 0、標準差 1；γ、β 是可學習參數。
  • BN 的 mean／STD 個數 = channel 數，不是每個像素一組。
  • 資料擴增只用在訓練資料，而且是在 Data Loader 取資料時即時產生。
  • 不要一開始就加正則化，先建立 Baseline；L2 太重會 underfitting。
  • CutOut vs Random Erasing：CutOut 是固定大小正方形、填 0；Random Erasing 是隨機長寬比與面積、填隨機值。
  • MixUp vs CutMix：MixUp 整張疊合；CutMix 局部替換、標籤依面積比例。

7. 自我測驗

1.（選擇）下列哪一種正則化方法最可能把不重要特徵的權重直接降為 0？

(B)。L1 會優先把不重要特徵的權重降為 0，有特徵選取效果；L2 是把所有權重一起變小（可以在 2.6 的元件看到兩者的差別）。

2.（選擇）關於 Batch Normalization，下列何者正確？

(C)。(A) 推論時用 running_mean／running_STD；(B) γ、β 是可學習參數；(D) BN 的目的是穩定分布，γ、β 學出來後標準差不一定是 1。

3.（簡答）為什麼「只看 Accuracy」不夠？請舉一個混淆矩陣能回答、但 Accuracy 回答不了的問題。

看解答
Accuracy 只給整體答對比例，看不出「哪一類比較差」、「錯成什麼」。例如模型是不是傾向把 8 判成 3、或把 4 判成 9，只有混淆矩陣的非對角線格子看得出來。

4.（計算）某篩檢模型結果：TP = 80、FN = 20、FP = 40、TN = 860。請計算 Accuracy、Recall、Precision、Specificity 與 F1。

看解答
Accuracy = (80 + 860) ／ 1000 = 0.94；Recall = 80 ／ 100 = 0.8；Precision = 80 ／ 120 ≈ 0.667；Specificity = 860 ／ 900 ≈ 0.956；F1 = 2 × 0.667 × 0.8 ／ (0.667 + 0.8) ≈ 0.727。觀察：Accuracy 看起來很高，但因為負例佔大多數，Precision 其實不高。可以在 2.3 的計算器按「自我測驗第 4 題」驗算。

5.（計算）BN 的 momentum = 0.9，running_mean 目前為 2.0，新的 batch mean 為 4.0，更新後 running_mean 是多少？另外，若 Early Stopping 的 P = 2，Val Loss 依序為 0.9、0.6、0.5、0.55、0.52，會在第幾個 epoch 停止？

看解答
running_mean = 0.9 × 2.0 ＋ 0.1 × 4.0 = 2.2。Early Stopping：最佳是第 3 個 epoch 的 0.5，第 4、5 個 epoch 都沒有更好，連續 2 個 epoch 沒進步 → 在第 5 個 epoch 停止，取回第 3 個 epoch 的權重（可以在 2.8 的元件驗算）。

6.（選擇）在 32×32 的 A 圖上用 CutMix 貼一塊 8×8 的 B 圖，標籤應為？

(D)。CutMix 的標籤依面積比例：\(64/1024=0.0625\)，所以 A 佔 \(1-0.0625=0.9375\)。(C) 是 16×16 的情況。
